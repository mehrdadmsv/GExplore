Welcome to the GExplore User Guide

Use this guide to help you learn GExplore's features and accelerate your research and analysis. GExplore provides comprehensive data on genes, mutations, proteins, and their expressions, making it easier for you to explore and analyze genetic information.


Start at the beginning, or visit each section individually to work your way through a project session. Each section of this guide provides detailed information and instructions on how to use GExplore's features effectively.

Last updated on Aug 1, 2024

Introduction

GExplore Overview

GExplore is a tool for large-scale mining of data related to gene or protein function in C. elegans. The interface is simple, and response times are fast to encourage large-scale exploratory searches. GExplore is designed to offer detailed insights into genetic data, enabling researchers and analysts to delve deep into genetic information.


The database contains selected genome-wide data sets, including protein domain organization, gene expression, and phenotype data, which are important indicators for gene and protein function. Data sets were obtained from Wormbase and processed to integrate data and to simplify searches.


This site should be useful for experimental planning of genome-scale experiments and survey-type queries. With this interface, you should be able to get quick answers to questions such as:

  • How many small secreted proteins are there?
  • Which putative cell surface receptors are expressed in neurons?
  • How many kinases expressed in muscle cells have mutants available?

We are continuously improving GExplore and its features. If you have any questions or feedback, please contact Dr. Harald Hutter.

August 2024 release (version 1.5)

GExplore version 1.5 is a major update including the following novel data sets and features:

  • All databases were updated to Wormbase release 292.
  • The domain organization for the proteomes of all nine core species in Wormbase was added to allow searches for proteins with certain domains in different nematode species.
  • Gene ontology data were added for all species.
  • The location of C. elegans mutations was mapped onto the domain organization of the proteins.
  • SAGE and RNAseq expression data were replaced by new stage-specific expression profiles from the modENCODE project (provided by the Waterston lab).
  • Best BLAST hits were replaced by orthologs as listed by Wormbase; a search option to identify C. elegans orthologs of human, mouse, Drosophila, or yeast genes was added.

Databases

GExplore consists of six different databases, each with its own search page.

Genes

The gene database contains selected datasets relevant to predict the putative function of genes/proteins. These include the domain organization of the protein, the general gene description, phenotype and expression data, gene interaction data, as well as gene ontology and disease associations. All data were downloaded from Wormbase. The database will be regularly updated. The current version is based on Wormbase release 292 (April 2024). The search interface allows the user to quickly identify groups of genes sharing certain features, e.g. all kinases that are expressed in muscle cells. Alternatively, the user can start with a large list (100s or 1000s) of candidate genes and filter them for certain characteristics. The quick response time and flexible output options allow for quick survey-type queries with large groups of genes in the input and/or output.

Mutations

Mutation data were downloaded from Wormbase (release 292, April 2024). Only exonic alleles and alleles affecting splice junctions are included. SNPs from wildtype isolates were excluded. The curated list of mutations should be enriched for alleles affecting the function of the protein. The location of the mutations was mapped onto the domain organization of the protein for a visual display of the location and nature of the mutations. For deletions a color code indicates whether the deletion is in-frame (purple) or causes a frameshift (red). Mutations were mapped to all known splice variants of the gene, so that splice-variant specific allele can be easily identified. For deletions the location of the endpoints is indicated ('outside' the gene, in an 'intron' or in an 'exon'). Display options include the possibility to show the protein sequence with the affected amino acid(s) highlighted. The WS292 version of the database contains 227,110 alleles in 19,661 genes (28,240 splice variants) with 12,998 deletions, 183,547 missense and 10,014 nonsense allele. The database contains an additional 8,763 alleles without molecular information.

Proteins

The protein database contains data from 13 Caenorhabditis species (C. becei, C. brenneri, C. briggsae, C. elegans, C. japonica, C. parvicauda, C. quiockensis, C. remanei, C. sulstoni, C. uteleia, C. tropicalis, C. waitukubuli, C. zanzibari) representing all branches of the Caenorhabditis phylogenetic tree. In addition, the database contains proteome data from 7 other namatode species (B. malayi, O. tipulae, O. volvulus, P. pacificus, P. redivivus, S. ratti, T. muris) that have high-quality data available. For comparison the database also contains the proteomes of the major "model organisms" (S. cerevisiae, D. melanogaster, D. rerio, M. musculus, H. sapiens). Protein data were downloaded either from Wormbase (nematode species) or the 'reference proteome site (https://www.ebi.ac.uk/reference_proteomes/) (model organisms). SMART was used for protein domain prediction. To allow for comparisons across species the database also contains information about homologs in all species in the database. The search interface allows the user to selected proteins with certain protein domains or certain domain arrangements for a selected species. The output can be limited to proteins with homologs in one or more of the other species. This can be used to quickly identify either nematode-specific genes or evolutionary conserved genes of a certain type (e.g. kinases).

Expressions
Expression (Stages)

The expression data for the different stages of the life cycle of C. elegans was obtained as part of the NHGRI modENCODE project in a collaboration of the Waterston (Max Boeck, Chau Huynh, LaDeana Hillier, University of Washington), Reinke (Guilin Wang, Dionna Kasper, Yale University) and Miller (Clay Spencer, Vanderbilt University) labs 1,2,3,4 Briefly, 18 samples were analyzed with RNA-seq. The results provided here are a subset of that data, derived from synchronized whole animals from embryonic and post-embryonic stages. For post-embryonic stages, two or more biological replicates were obtained; the weighted averages are provided. For the embryonic stages, 4 independent time series were collected, taking samples every 30 minutes (some samples were lost from technical failures). For details of data collection and analysis see ref 4. Expression units Expression for each gene is given in dcpm units (depth of coverage per million 35 base reads)1. This measure has the advantage of providing a base-pair resolution estimate of expression, simplifying the analysis of shorter features such as exons and splice junctions. A dcpm value of 1.5 reflects an average level of expression. Values between 0.003 and 0.1 generally represent significant expression. Expression (Tissues)

The expression data for cells/tissues at the L2 stage was generated using Single cell Combinatorial Indexing RNAseq (sci-RNAseq). For details of data collection and analysis see Cao et al. (2017). Briefly, the expression profile of nearly 50,000 cells from L2 larval stage was determined by sci-RNA-seq. From these data, consensus expression profiles for 27 cell types were defined. The profiles available through GExplore correspond to data in Tables S2 to S4 of Cao et al. (2017). Images of expression profiles correspond to the sample shown in Figure S14. Expression levels of each gene are shown in transcripts per million (TPM). Enrichment data were precalculated and are presented as the "ratio" of the gene's expression in the most highly vs. the 2nd-most highly expressing cell type. "qval" is the false detection rate at which you can say the gene is differentially expressed between the highest and 2nd-highest expressing cell types. For reference: in Cao et al. (2017) a gene is called "cell type enriched" if ratio >= 5 and q-val < 0.05.

Expression (Embryo)

The expression data for the embryonic tissues was generated using RNA-seq. For details of data collection and analysis see Warner et al. (2019). Briefly, synchronized populations of embryos expressing tissue-specific fluorescent markers were sampled at 90-min intervals for five time points starting 120 min after embryo isolation about halfway through gastrulation (t0). The last time point (480 min after isolation, t4) corresponds to the early 3-fold stage, when cells begin terminal differentiation, but before the cuticle forms. In total, time series data for five different tissues/organs (hypodermis, intestine, pharynx, muscle and neuron) and two lineage-specific populations (ABa and ABala) were produced. Expression levels were calculated in transcripts per million (TPM).

Search Fields

Overview

You only need to enter search terms in one of the search fields. If you enter search terms in multiple fields, they will be combined for an AND Search (the result will contain only genes that fulfill all search criteria).

Text search fields on the "Genes" search page (Description, Phenotype, Expression, Gene Ontology, and Disease Associations) will return any match to the search term(s). You can:

  • Use comma-separated lists for an OR Search
  • Use Boolean logic to combine search terms: ((axon and dendrite) or neuron) not muscle
Search Type Example Result Use Case
AND Search axon and dendrite Only results containing both "axon" and "dendrite". Use when you want to narrow down results to items that meet all criteria. This gives fewer, more specific results.
OR Search axon or dendrite Results containing either "axon", or "dendrite", or both. Use when you want to broaden the search to include items that match any of the criteria, increasing the number of results.
What to expect?

On the output page, search terms for the text search fields will be highlighted for easier recognition.

Once the search is executed, the results will be displayed in table format. On the output page, you can:

  • Choose which additional data to display.
  • Determine the output format (example: table columns, export options).
Gene Search Field

The gene search field accepts the following identifiers (or any combination):

  • Wormbase gene ID: WBGene00003738
  • Gene sequence name: F54F3.1
  • Locus name: nid-1
  • Protein sequence name: F54F3.1a

Names can be separated by commas or any whitespace character (space, tab, newline). You can enter (or copy) a list of thousands of gene names for a single search.

* can be used as a wildcard character. For example, unc-* means all gene names beginning with unc-.

Protein Domain Search Fields
Domain

Enter one or more of the domain abbreviations from the table of abbreviations or SMART/Pfam identifiers (example: SM00273, PF12423).

Domain Pattern

Use this field to search for certain domain combinations. Think of a protein as a linear sequence of domains like IG IG IG FN3 FN3 TM 324. Domain abbreviations in this field (but not in the domain field) are case-sensitive! You can use wildcards (* acts as a wildcard for 0 or more domains) and numbers (but no Boolean terms) in the following way:

Pattern Input Description
IG IG IG 3 IGs in a row with no other domain in between.
IG*FN3 The IG domain is eventually followed by an FN3 domain.
3IG Expanded to IG IG IG: 3 IG domains in a row. Ensure there’s no space between the number and the domain abbreviation.
3IG% Represents IG*IG*IG: 3 IGs with other domains interspersed (% acts as a wildcard during expansion).
3-5IG Represents 3 to 5 IG domains: IG IG IG, IG IG IG IG, or IG IG IG IG IG.
<3IG FN3 Translated as IG FN3 or IG IG FN3: meaning at least 1 but no more than 2 IGs followed by FN3.
>3IG FN3 Translated as IG IG IG IG*FN3: meaning at least 4 IGs followed by FN3.
Text search fields
Description Search Field

" Legacy description" is equivalent to "Legacy manual gene description" in Wormbase, the "automated description" is the top level description under the “Overview” tab in Wormbase.

Phenotype and Expression Search Fields

Phenotype and expression data is Wormbase used defined vocabularies. The search fields have an autosuggest function, which suggest search terms when the user starts to type into the field. You do not have to use the suggested terms, you can use any word for searching, the search will find any term that contains the search word. "Tissues and Stages (genomic studies)" refers to data that either came from single-cell RNAseq studies or from enrichment analysis of high-throughput studies, where expression in specific tissues was compared to whole animals.

Gene Ontology and Disease Association Search Fields

These search fields also use defined vocabularies and have an autosuggest function.

Tools

Compare Tool

Compare provides an easy way to find unique and common genes within two sets of genes (two lists of terms of any kind). The input fields accept a comma-separated list of terms such as the "list of genes/proteins" found on the results pages of GExplore. The out consists of three lists: the common genes and the unique genes from each of the two input sets.

Convert Tool

The convert input field accepts any combination of C. elegans gene identifiers: Wormbase gene ID (WBGene00003738), gene sequence name (F54F3.1), locus (nid-1), protein sequence name (F54F3.1a), wormpep ID (CE18731), Uniprot ID (Q93791). The output consists of a table with all the identifiers for all the genes in the input field. This can be used to standardize identifiers that come from different sources or to convert one set of identifiers into another one.
