Search for Mutations in C. elegans Genes

The database includes alleles affecting exons, splice junctions, and those without positional information from Wormbase release 292 (April 2024).

The Million Mutation Project offers over 2,000 heavily mutagenized strains, while the KO consortium is generating null mutations using CRISPR/Cas9.
