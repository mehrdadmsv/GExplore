Search for mutations in C. elegans genes

The database contains alleles affecting exons and splice junctions of protein-coding genes as well as alleles without positional information in Wormbase. Data are from Wormbase release 288 (April 2023).

The Million Mutation Project provides a collection of more than 2,000 heavily mutagenized strains. The C. elegans Gene Knockout Consortium (KO consortium) is working to produce null mutations in all identified and predicted genes currently using a CRISPR/Cas9 strategy.
